# @dafne/frontend-changelog

A record's change log for any frontend app: the history sheet and its
texts. TypeScript sources compiled by Next (`transpilePackages`).
Relative imports end in `.ts`/`.tsx`.

- `.`: plain data, for server and client: `CHANGELOG_MESSAGES` (merged by
  the apps under `changelog`), `formatChangeValue`, `diffListElements` (a list's elements added,
  removed, or changed with their fields) and `diffList` (their counts), the types
  (`ChangesPage`, `LoadChanges`: what a resource's server action gives).
- `./components/changelog-sheet`: `ChangelogSheet`, opened by the page
  (`open`, `onOpenChange`, e.g. a History item of the detail actions);
  loads with `load` when opened, 20 changes at a time, each a `Trace` of
  `@dafne/frontend-ui`. `fields` names the resource's fields
  (`ChangeFieldConfig`: `label`, then `value` for one value or `summary`
  for the whole change).
- `./components/change-values`: ready-made `value`/`summary`:
  `EditedSummary` ("added"/"edited", for rich text), `ListChangeSummary`
  (a list's elements matched by a key, counted), `ListChangeDetails` (the
  same, one line per element: added with its fields, removed, or its
  fields from → to; `fields` names and shows them), `ResolvedName` with `nameCache` (a
  record's name for its id; looked up in an effect, never while rendering:
  server actions update the router).
- A resource's sheet (e.g. `SalesOrderChangelogSheet`) is generated by
  `dafne g frontend-resource` for a logged resource; it lives with the
  resource, not here.
